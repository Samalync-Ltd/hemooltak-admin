# Hemoltak Admin Dashboard

Standalone React + Vite application for the Hemoltak administration portal.

## Run locally

```bash
npm install
npm run dev
```

Open the URL printed by Vite and use `/admin/login` for the admin sign-in screen.

## Build

```bash
npm run build
```

The main platform lives in `../hemola-frontend` and no longer bundles admin routes.
